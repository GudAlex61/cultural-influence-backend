# Дизайн-макеты «Культурный след»

В папке находятся три редактируемых мобильных макета размером `390 × 844 px`:

- `feed.svg` — лента: вертикальное видео, данные произведения поверх видео, лайки, раскрытие текста и переход к следующему отрывку;
- `draft.svg` — экран добавления: одна карточка-черновик с доступными для заполнения полями без сохранения;
- `gallery.svg` — плитка: опубликованные произведения в два столбца и серверный GET-фильтр по году публикации.

SVG-файлы можно перетащить в Figma или импортировать через **File → Place image**. Текст, фигуры, группы, заливки и обводки после импорта остаются редактируемыми. Для итогового файла Figma следует поместить три макета рядом и назвать фреймы «Лента отрывков», «Новый отрывок» и «Произведения».

## Визуальный аналог

Источник стилистики — российский гуманитарный просветительский портал [«Культура.РФ»](https://www.culture.ru/), посвящённый литературе, кино, театру, музыке и культурному наследию. Связь с темой проекта прямая: приложение также работает с произведениями литературы и кино, авторами и культурным влиянием.

У портала заимствованы не логотип и не фирменное название, а общие приёмы интерфейса:

- контрастная редакционная типографика: крупные заголовки с засечками и нейтральный шрифт для служебного текста;
- большие изображения и видео как главный элемент материала;
- короткие прописные рубрики над заголовками;
- сдержанный светлый фон и красные акценты;
- карточная подача культурных материалов;
- тонкие разделители, свободные поля и лаконичные пиктограммы.

## Палитра — ровно три базовых цвета

| Назначение | Цвет | Использование |
|---|---|---|
| Акцентный красный | `#ED2324` | кнопки, активная навигация, лайки, метки и hover-состояния |
| Графитовый | `#3C3C3C` | основной текст, иконки, тёмные поверхности видео |
| Белый | `#FFFFFF` | фон, карточки и контрастный текст |

Эти значения приведены в [официальном брендбуке платформы PRO.Культура.РФ](https://pro.culture.ru/documentation/brand-book-pro.pdf): красный обозначен как главный акцентный цвет, `#3C3C3C` — как основной цвет шрифта. В макетах дополнительные визуальные оттенки получены только прозрачностью этих трёх цветов, поэтому отдельные цвета в палитру не добавляются.

## Параметры интерфейса

- размер экрана: `390 × 844 px`;
- боковые поля: `16–20 px`;
- сетка плитки: 2 колонки по `171 px`, промежуток `16 px`;
- радиус основной карточки: `18 px`;
- радиус карточки плитки: `12 px`;
- поля формы: высота `44 px`, радиус `8 px`;
- основная кнопка: высота `42 px`, радиус `21 px`;
- нижняя навигация: `72 px`, три равные зоны;
- заголовки: Georgia Bold как системный аналог редакционного шрифта с засечками;
- интерфейсный текст: Arial как нейтральный системный шрифт.

## Состояния для реализации в CSS

- карточка: при наведении поднимается на `2 px`, тень усиливается;
- основная кнопка: при наведении становится графитовой;
- ссылка или элемент навигации: при наведении становится красным;
- поле формы: при фокусе получает красную обводку;
- переходы: `transition: 0.2s ease`.

Макеты являются самостоятельной адаптацией под учебную тему и не используют логотип, фотографии или другие охраняемые материалы портала. Градиентные обложки — нейтральные заполнители; при реализации приложения вместо них должны использоваться файлы из публичного бакета MinIO.
