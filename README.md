# Репозиторий backend по курсу «Разработка интернет-приложений»

## «Культурный след» — лабораторная работа № 1

Приложение на Node.js, NestJS, TypeScript и Handlebars. Предметная сущность — `artwork_excerpts` (отрывки произведений искусства). Данные хранятся в одной коллекции без базы данных и клиентского JavaScript.

Источник частично заимствованного оформления — [страница театров «Культура.РФ»](https://www.culture.ru/theaters). Использованы точные цвета `#3C3C3C`, `#FFFFFF`, `#ED2324`, серая панель, крупные изображения с затемняющим наложением, небольшое скругление карточек и hover.

## Запуск

Требуется Node.js, npm и Docker Desktop.

```bash
npm install
docker compose up -d
npm run start:dev
```

Приложение: `http://localhost:3000/artwork_excerpts`

MinIO: `http://localhost:9001` (логин `root`, пароль `rootpassword`). Изображения и видео хранятся в публичном бакете `artwork-excerpts`.

## Два поля по теме

- `artworkCreationDate` — дата создания произведения;
- `citationCount` — количество цитирований.

Фильтрация плитки выполняется на сервере по точной дате создания произведения.

## Три GET-обработчика

- `/artwork_excerpts/feed/:id?next=true` — одна карточка ленты по ID либо следующая карточка;
- `/artwork_excerpts/draft` — единственный черновик с формой без сохранения;
- `/artwork_excerpts?artworkCreationDate=1865-11-26` — плитка и серверная фильтрация календарём.

На странице ленты одновременно присутствуют медиа только одной карточки. Переход выполняется кнопкой «Далее», без прокрутки и клиентского JavaScript. Поля выбора изображения и видео на странице добавления открывают системный проводник, но форма не создаёт запись.
