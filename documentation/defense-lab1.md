## Короткий сценарий устного показа

### 1. Тема и назначение

> Моя тема — расчёт индекса культурного влияния на основе цитирований. Предметная услуга — отрывок произведения искусства, например литературы или киносценария. В будущих работах пользователь будет формировать заявку на расчёт условного индекса по упоминаниям, референциям и цитатам. В первой лабораторной реализованы просмотр и серверная фильтрация отрывков.

### 2. Дизайн

> Я разработал три портретных мобильных экрана: ленту, добавление и плитку. В качестве тематического визуального аналога выбрана «Культура.РФ». Использованы три базовых цвета `#ED2324`, `#3C3C3C`, `#FFFFFF`, контрастная редакционная типографика, крупные медиа, карточная подача, тонкие разделители и эффект наведения. Логотип и название ресурса не копируются. CSS вынесен в отдельный файл.

Показать скриншоты 1–9 и соответствующие живые страницы.

### 3. Маршруты и Network

> Всего есть три GET-обработчика. Лента принимает необязательный ID и query-параметр `next`. Черновик выбирается по статусу `draft`. Плитка принимает числовой параметр `publicationYear`, фильтруется на сервере и возвращает его обратно в поле формы.

Показать скриншоты 10–12. Нажать карточку, затем «Следующий», выполнить фильтрацию. Объяснить различие path-параметра и query-параметра.

### 4. Модель и MinIO

> Данные находятся в одном массиве `ArtworkExcerpt`, базы данных пока нет. Изображение и видео заданы двумя отдельными латинскими ключами. Полные URL указывают на публичный бакет MinIO. Массив `likedByUserIds` хранит ID пользователей, а число лайков вычисляется в контроллере.

Показать скриншоты 13–17, затем открыть один URL медиа напрямую.

### 5. Обработчики

> Обработчик ленты исключает удалённые и черновые записи из публичного просмотра и умеет выбрать следующую опубликованную запись. Обработчик добавления находит единственный черновик, но форма ничего не сохраняет. Обработчик плитки показывает только опубликованные записи и фильтрует их по году. Клиентский JavaScript не используется.

Показать скриншоты 18–19.

### 6. Архитектура

> В терминах MVC модель — `ArtworkExcerpt` и массив данных, контроллер — обработчики NestJS, представление — Handlebars-шаблоны и CSS. Сервер получает GET-запрос, готовит объект данных и возвращает готовый HTML.

## Частые проверочные вопросы

**Почему фильтр GET, а не POST?**  
Фильтр только читает данные и не меняет состояние. Его значение удобно выразить в URL и повторить тем же запросом.

**Почему год — хороший фильтр?**  
Это числовое атомарное поле предметной области, оно отображается на странице и не является текстовым описанием.

**Почему число лайков не хранится отдельным полем?**  
Оно вычисляется по `likedByUserIds.length`, как требует задание. Так не возникает расхождения между списком лайков и их числом.

**Почему форма добавления не сохраняет данные?**  
В первой лабораторной разрешено только заполнение полей без создания или редактирования. Сохранение появится после подключения базы данных в следующей работе.

**Почему MinIO?**  
MinIO является объектным хранилищем. В модели хранятся ключи объектов, а браузер получает изображения и видео по URL публичного бакета.

**Что означает `next=true`?**  
Это query-параметр GET-запроса. Контроллер находит позицию записи с указанным ID среди опубликованных записей и выбирает следующую.

**Чем Web отличается от Интернета?**  
Интернет — сетевая инфраструктура, Web — служба связанных ресурсов и приложений, использующая HTTP/HTTPS поверх Интернета.

## Git без GitHub CLI

Если удалённого репозитория ещё нет:

1. На github.com нажать `New repository`.
2. Задать имя, например `cultural-influence-web`.
3. Не добавлять README и `.gitignore`, если локальная история уже существует.
4. Выполнить локально команды, подставив адрес своего репозитория:

```powershell
cd C:\Users\aleks\cultural-influence-backend
git remote add origin https://github.com/USER/cultural-influence-backend.git
git push -u origin lab1-cultural-influence
```

Если `origin` уже существует, повторно добавлять его нельзя; проверить адрес можно командой `git remote -v`.
