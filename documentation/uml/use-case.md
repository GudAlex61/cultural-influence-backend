# Диаграмма прецедентов

## Назначение

Диаграмма показывает функции итоговой системы «Культурный след» с выделением функций, уже представленных в лабораторной работе № 1. Она описывает требования пользователя, а не внутреннее устройство NestJS.

## Акторы

- **Гость** — неаутентифицированный посетитель, который просматривает и фильтрует отрывки.
- **Создатель заявки** — аутентифицированный пользователь; обладает возможностями гостя и формирует собственные заявки.
- **Модератор** — аутентифицированный пользователь с правом просмотра и обработки всех заявок; обладает возможностями гостя.

## Прецеденты лабораторной № 1

- просмотреть плитку опубликованных отрывков;
- отфильтровать отрывки по году публикации;
- открыть выбранный отрывок в ленте;
- перейти к следующему опубликованному отрывку;
- просмотреть страницу добавления с единственным черновиком;
- заполнить поля страницы добавления без сохранения.

Связи:

- «Отфильтровать по году» расширяет просмотр плитки, потому что фильтр необязателен;
- «Открыть отрывок в ленте» может выполняться из просмотра плитки;
- «Перейти к следующему отрывку» расширяет просмотр одного отрывка;
- заполнение полей включается в просмотр страницы добавления, при этом сохранения в лабораторной № 1 нет.

## Планируемые прецеденты итоговой системы

- зарегистрироваться и войти;
- создать и изменить черновик заявки;
- подтвердить заявку;
- просмотреть собственные заявки;
- рассчитать индекс `I = M + 2R + 3C`;
- просмотреть все заявки и изменить статус заявки как модератор.

## Как перенести или исправить диаграмму в StarUML

1. Открыть `cultural-influence.mdj` в StarUML.
2. Если расположение элементов изменилось из-за версии программы, выбрать диаграмму `Прецеденты системы` и выровнять акторов и овалы, не меняя модель.
3. Если файл не открывается, создать один проект StarUML и одну `Use Case Diagram`, затем вручную добавить элементы из списков выше либо использовать `use-case.puml` как визуальный образец.
4. Все последующие диаграммы курса добавлять в этот же `.mdj` через `Model → Add Diagram`; не создавать отдельный файл на каждую лабораторную.
5. Перед вставкой диаграммы в отчёт убрать пересечения линий, проверить читаемость подписей и экспортировать изображение с размером шрифта, сопоставимым с текстом отчёта.

## Что сказать на защите

> Основной актор первой лабораторной — гость. Он просматривает плитку опубликованных отрывков, применяет серверный фильтр по году, открывает карточку по ID и переходит к следующей через query-параметр. Страница добавления пока только показывает черновик и разрешает заполнить поля без сохранения. Создатель заявки и модератор показаны как будущие роли итоговой системы.
