# Документация к лабораторной работе № 1

Тема проекта: **«Расчёт индекса культурного влияния на основе цитирований»**.

Предметная сущность («услуга» в общей формулировке задания) — **отрывок произведения искусства** (`ArtworkExcerpt`). Будущая «заявка» — запрос на расчёт условного индекса влияния произведения или автора по числу упоминаний, референций и прямых цитирований.

## Состав папки

- `technical-specification-module-1.md` — черновик ТЗ на итоговую систему для первого модуля;
- `uml/use-case.md` — состав и пояснение диаграммы прецедентов;
- `uml/use-case.puml` — переносимый исходник диаграммы PlantUML;
- `uml/cultural-influence.mdj` — единый проект StarUML с моделью прецедентов;
- `control-questions-lab1.md` — письменные ответы на контрольные вопросы;
- `screenshots-lab1.md` — точный чек-лист скриншотов 1–19;
- `lecture-01-web-mvc.md` — краткий конспект первой лекции;
- `defense-lab1.md` — порядок подготовки и сценарий защиты.

## Важные оговорки

1. Markdown-файлы являются содержательной заготовкой. Если преподаватель требует `.doc`/`.docx`, текст следует перенести в документ с оформлением по требованиям кафедры.
2. Все UML-диаграммы курса требуется хранить в одном файле StarUML. Поэтому новые диаграммы в следующих лабораторных надо добавлять в `uml/cultural-influence.mdj`, а не создавать отдельные проекты.
3. Файл `.mdj` содержит UML-модель и диаграмму прецедентов. Перед сдачей его нужно открыть в установленной версии StarUML, проверить расположение элементов и при необходимости выровнять их вручную.
4. PlantUML — запасной переносимый исходник. Он не заменяет требуемый файл StarUML, но позволяет быстро восстановить содержание диаграммы.
5. Конспект не отменяет требование преподавателя показать собственные конспекты всех уже прошедших лекций.
